Privacy Policy – Horror Videos Uploader

Last updated: 8 November 2026 · Operated by the YouTube channel “Horror Videos” (@horror_videos_hindi) · Contact: horrorvideos6637@gmail.com

1. What this application is

“Horror Videos Uploader” (Google Cloud project healthy-highway-514113-e3) is a private, internal tool used only by the owner of the YouTube channel “Horror Videos” to upload and schedule that channel’s own YouTube Shorts. It is not offered, sold or made available to any other person or organisation. It has exactly one user: the channel owner.

2. Use of YouTube API Services

This application uses the YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms.

Google’s handling of data is described in the Google Privacy Policy: https://policies.google.com/privacy (also http://www.google.com/policies/privacy).

3. What information we access

  • YouTube upload permission (youtube.upload): used only to upload our own channel’s Short videos (videos.insert) with a title, description, tags and a scheduled publish time.
  • Read-only channel information (youtube.readonly): used only to read our own channel’s name (channels.list, mine=true) to confirm that the correct channel is connected.

We do not access, collect or process any data about other YouTube users, viewers, subscribers, comments, analytics or any other channel.

4. What we store and where

  • The OAuth access/refresh token for our own channel, stored only on the channel owner’s computer in a file readable only by that user. It is never shared or transmitted anywhere except to Google’s servers to make the API calls above.
  • A local log of our own uploads (video file name, the YouTube video ID returned by the API, and the scheduled publish time) so the tool does not upload the same Short twice.

No personal data of any other person is collected or stored. We do not use cookies, tracking, advertising identifiers or analytics in this application.

5. How we use and share information

The information above is used only to upload and schedule our own videos. It is not sold, rented, shared with or disclosed to any third party, and it is not used for advertising or profiling.

6. Data retention and deletion

  • The upload log is kept only as long as needed to avoid duplicate uploads and is deleted when it is no longer needed. Stored YouTube API data is refreshed or deleted at least every 30 days, as required by the YouTube API Services Developer Policies.
  • Access can be revoked at any time through the Google security settings page: https://security.google.com/settings/security/permissions (or https://myaccount.google.com/permissions). When access is revoked or the tool is no longer used, the stored token and the upload log are deleted from the computer within 7 days.
  • To request deletion or ask any question about this policy, email horrorvideos6637@gmail.com; we respond within 7 days.

7. Changes

If this policy changes, the updated version will be published at this address with a new “Last updated” date.
